**Top findings**

1. **Terminal-latch admission window — VERIFIED-IN-CODE.**  
   Opening passes its check; another thread latches loss and trips the fence. Arming clears `lost`; admission can succeed before arming rechecks the end. Highest direct ownership risk; data loss was not demonstrated.

2. **Counter recreation races a prepared mount claim — VERIFIED-IN-CODE; loss risk INFERRED.**  
   Counter is missing and mount probe observes absence. An older prepared starter creates the mount; counter recreation then lands independently. The model’s atomic absence-and-mint excludes this inconsistency.

3. **Remote publication can outlive shutdown drain — VERIFIED-IN-CODE.**  
   Timed-out publish returns unresolved; task count reaches zero. Drain permits farewell; outstanding snapshot/checkpoint request subsequently lands. `NoLandingAfterFarewell` is unsupported; conditional checkpoint rules limit damage.

4. **Log durability is fused with authoritative acknowledgment — VERIFIED-IN-CODE.**  
   Wedge retry creates its log, then checkpoint publication fails. Code withholds acknowledgment; model acknowledges immediately. Existing invariants cannot detect missing frontier authority.

5. **Relink deletion actor is overrestricted — VERIFIED-IN-CODE.**  
   Receiver publishes precommit; source confirms; source removes its ref before promotion. Code relies on precommit protection, which this composition omits. Its green deletion invariant does not audit that GC interval.
