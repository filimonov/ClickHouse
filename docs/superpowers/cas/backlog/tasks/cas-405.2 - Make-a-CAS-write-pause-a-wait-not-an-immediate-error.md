## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
system.cas_mounts and the docs say writes are paused, but a write that finds too little lease left throws NETWORK_ERROR (210) at once (CasOperation::gate -> NoBudget), and every foreground read and write gives up at the fixed 90 s Retry::standard() window (Backend/CasRetry.h, also once, untilLeaseSafe). Measured (tmp/cas405/REPORT.md): 824 insert errors in a 120 s outage with the 30 s lease, 772 of them immediate admission refusals. Goal: a write waits for the renewal within a bounded, configurable window; the client sees latency, not an error, for outages shorter than the window. Design first, owner approval before code.
