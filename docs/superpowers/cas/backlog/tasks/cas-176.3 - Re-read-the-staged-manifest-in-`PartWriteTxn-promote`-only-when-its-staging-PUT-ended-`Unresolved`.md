## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`PartWriteTxn::promote` re-reads and validates the manifest body this same writer staged seconds earlier (`R/Pool/CasPartWriteTxn.cpp:824-832`, `op.read` at `:828`), failing closed on absence.
That is one GET per part publish, part of the 108.7 GET/part insert figure.
decision-5: read only when the staging PUT ended `Unresolved` (0.05% of conditional writes); otherwise trust the committed etag.
This item was gated "do not touch without an explicit user go-ahead" as write-path verification semantics under the spirit of the protocol veto. decision-5 is that go-ahead.

Provenance: BACKLOG/ref-protocol.md#part-publish-zero-gets item 3 and BACKLOG/performance.md#writepath-candidates-post-stage1 item (5). Verified 2026-09-26 against b1c34d03479 and 0dbbd797792 (read at :828 on both).
