## Description

<!-- SECTION:DESCRIPTION:BEGIN -->
`DiskEncrypted` does not override `isContentAddressed` (base `false`, `src/Disks/IDisk.h:477`; only `ReadOnlyDiskWrapper.h:96`
forwards). Every CA-aware branch therefore takes the plain path over a CA pool: whole-part transaction choices
(`DataPartStorageOnDiskBase.cpp`), relink fetch (`DataPartsExchange.cpp`), the projection parent-transaction rule
(`IMergeTreeDataPart.cpp`, `MergeTask.cpp`) and BACKUP-restore (`MergeTreeData.cpp`). Result today: loud per-file autocommit
rejections. Forwarding alone is not enough; the encrypted transaction must also provide the whole-part transaction CAS needs.

Provenance: BACKLOG/operability-and-introspection.md#encrypted-wrapper-hides-content-addressed (2031-triage CAS-060); verified 2026-09-26 against dd0ed2f263a and 0dbbd797792.
